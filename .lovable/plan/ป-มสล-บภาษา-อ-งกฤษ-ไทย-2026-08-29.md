# ปุ่มสลับภาษา อังกฤษ / ไทย

เพิ่มปุ่มสลับภาษาบนหัวเว็บ กด TH แล้วข้อความทั้งเว็บเปลี่ยนเป็นไทย กด EN กลับเป็นอังกฤษ และจำค่าที่เลือกไว้เมื่อกลับมาเข้าใหม่

## สิ่งที่จะทำ

1. **ตัวจัดการภาษา** — สร้าง context เก็บภาษาปัจจุบัน (`en` / `th`) พร้อมบันทึกลง localStorage และตั้ง `lang` ของหน้าเว็บให้ถูกต้อง ค่าเริ่มต้นคืออังกฤษ
2. **คลังคำแปล** — ไฟล์เดียวเก็บข้อความทั้งหมดเป็นคู่ en/th ครอบคลุมทุกหน้า: Landing, Story, Discover, Skill Detail, Mission, Dashboard, Opportunities, Employer (Talent Radar + Candidate), Future Profile Preview, เมนูบนสุด, และหน้า 404
3. **ปุ่มสลับภาษา** — ปุ่มเล็กแบบ EN | TH อยู่บนแถบนำทาง (`TopNav`) และบนหัวหน้าแรก ตัวที่เลือกอยู่จะเน้นด้วยสีส้ม signal
4. **แทนที่ข้อความในทุกหน้า** — เปลี่ยนข้อความที่ hardcode ทั้งหมดให้ดึงผ่านตัวแปลภาษา
5. **ชื่อแรงค์** — Potential/Bronze/Silver/Gold/Diamond คงชื่อเดิมทั้งสองภาษา (เป็นชื่อระดับของแบรนด์) แต่คำอธิบายรอบๆ จะแปล

## รายละเอียดทางเทคนิค

- `src/lib/i18n.tsx`: `LanguageProvider`, hook `useT()` คืนฟังก์ชัน `t(key)` และภาษาปัจจุบัน; อ่าน localStorage ใน `useEffect` เพื่อเลี่ยง hydration mismatch
- `src/lib/translations.ts`: object `{ en: {...}, th: {...} }` คีย์แบบ `landing.hero.title`
- ห่อ `LanguageProvider` ไว้ใน `src/routes/__root.tsx` ร่วมกับ `SiuuuProvider`
- ข้อความที่ AI สร้าง (ชื่อสกิล มิชชัน ผลประเมิน) ยังคงเป็นภาษาที่ AI ตอบมา — ส่วน fallback demo data จะมีเวอร์ชันไทยด้วยเพื่อให้เดโมเป็นไทยครบ
- `head()` meta ของแต่ละหน้ายังคงเป็นอังกฤษ (SEO)
